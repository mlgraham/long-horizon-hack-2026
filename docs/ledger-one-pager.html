ledger — resumable agent state that survives a change of host

The agent's history is disposable; the state that matters is a dated, falsifiable ledger in the repo that any fresh session, on any host or model, can read in two minutes.

The verbs · one small CLI, plain Markdown under .ledger/

ledger note "…"Appends an entry stamped by the system clock, never by an argument.
ledger gate add / pass / failPre-registers a threshold, deadline, owner and kill criterion, then records what was measured.
ledger obligation addRecords an unproved claim and whether its hypothesis can be met at all.
ledger pauseWrites the ⏸ entry: what to resume, caps, open rulings, first file to read.
ledger resumePrints the two-minute brief, the only thing a new host needs in context.
ledger watch / tickOne loop: fetch the topic, distill a delta, note it, discard the raw page.

Every verb also posts one event: ts, kind, host, model, gate, text, tokens_in, tokens_out, bytes_discarded. No database is needed to run.

The second host is hosts/claude_code.sh: a fresh headless Claude Code session whose whole context is ledger resume (24 lines in the dry run). It read three files, wrote the summary and left three clock-stamped notes. hosts/loop.py offers the same loop on Ollama or the Anthropic API. AWS Bedrock was dropped because no AWS account is available today. A failed gate drops that sponsor from the pitch, never the core.

The 3-minute demo

  1. Watch live. ledger watch pulls a real topic through Nimble; the Liquid delta lands in STATUS.md and the raw page's bytes are discarded.
  2. Kill mid-task. Stop under Claude Code with the tests failing. Show the ⏸ pause entry and its FLUX cover.
  3. Resume elsewhere. A fresh headless session gets only ledger resume, fixes the code, runs the tests until green and flips the gate with the line it measured.
  4. Ask what changed. One SQL query in RawTree returns the last hour of events; the board is rendered from it.
